# CLAUDE.md — ตัวแก้ไขเซฟ Way of Xian (WOX2)

เครื่องมือแก้ไฟล์เซฟเกม Way of Xian ที่ทำงานในเครื่องเท่านั้น (ไม่มี `fetch`/อัปโหลด) รายละเอียดผู้ใช้อยู่ใน `README.md`

## ไฟล์

| ไฟล์ | หน้าที่ |
|---|---|
| `ตัวแก้ไขเซฟรี.html` | โครงหน้า โหลด `editor.css` / `editor.js` แบบ relative (ชื่อไฟล์จริงอาจเพี้ยนตอนอัปโหลด) |
| `editor.css` | สไตล์ light/dark + มือถือ |
| `editor.js` | ทั้งหมด: codec (บล็อก `/*CODEC*/…/*END*/`), ตาราง, logic แก้ค่า, UI, บันทึก |
| `wox.js` | CLI: `unseal` / `seal` / `verify` / `check` |
| `app-*.js`, `c-*.js` | bundle ของเกม อ่านอย่างเดียว ใช้อ้างอิงและเทียบ ห้ามแก้ |

กฎของ `lint` มาจากตารางเกมที่ `check` ยืนยันแล้ว (พรสวรรค์/คู่ขัดกัน/ช่อง/ราก/ธาตุ/กำเนิด/ดวงชะตา) ส่วนกฎ `statSrc` รวม = `stats` และเพดาน `capSeen` มาจาก README และตรรกะของ `editor.js` ยังไม่ได้ยืนยันกับเซฟจริง จึงรายงานเป็น warn ไม่ใช่ error

bundle แต่ละไฟล์ ~5.5MB อย่าเปิดทั้งไฟล์ ให้ค้นด้วย regex แล้วตัดเฉพาะช่วง

## รูปแบบเซฟ

`WOX2<แฮช 16 hex>~<ข้อความเข้ารหัส>` · แฮชและการเลื่อนอักขระ ASCII 33–126 สร้างจากรหัสลับเดียวกับเกม · ตอนเปิดคำนวณแฮชซ้ำ ไม่ตรงให้ปฏิเสธ · รับเฉพาะ WOX2 (ไฟล์ gzip คลายให้เอง)

## คำสั่ง

```bash
node wox.js check [--dir โฟลเดอร์]   # เทียบ codec + ตารางใน editor.js กับ bundle
node wox.js verify <ไฟล์เซฟ>          # ตรวจตรา, round-trip, เทียบ codec ของเกม
node wox.js unseal <ไฟล์เซฟ> [-o out.json|-]
node wox.js seal <json> [-o out|-]    # ใส่ tampered ให้เสมอถ้ายังไม่มี
node wox.js diff <เก่า> <ใหม่> [--all]  # เทียบเซฟ แสดงเฉพาะจุดที่ต่าง (WOX2 หรือ JSON)
node wox.js lint <ไฟล์> [--strict]    # ตรวจความสมเหตุสมผลตามตารางเกม (exit 1 เมื่อมี error)
node --check editor.js                # syntax
```

`check` ต้องผ่านทุกรายการก่อนส่งงานที่แตะ codec หรือตาราง ทดสอบแล้วว่าตรวจจับตารางที่ถูกแก้ได้จริง

## กฎที่ห้ามละ

- ป้าย `state.tampered` (`{at, why:"hand"}`): ตัวแก้ไขต้องใส่ให้เสมอเมื่อมีการแก้ และ UI ต้องไม่ให้แก้/ลบ/เพิ่มคีย์นี้ (`PROT` ใน `editor.js`) ห้ามเพิ่มตัวเลือกข้ามป้าย ทั้งใน UI และ `wox.js seal`
- บันทึกไฟล์ที่แก้ต้องอัปเดต `savedAt` (เกมใช้ตัดสินสล็อตตอนซิงก์) แต่ไฟล์ที่ไม่ได้แก้ต้องออกมาตรงไฟล์เดิมทุกตัวอักษร
- รหัสพรสวรรค์ที่ไม่อยู่ในตาราง `TAL` ห้ามเพิ่มให้ (เซฟอาจพัง)
- แก้ค่าสถานะต้องผ่าน `setStat` เพื่อให้ `statSrc` / `capSeen` / `yearFrom` สอดคล้อง
- ห้ามกล่าวว่าตารางตรงกับเกมจนกว่า `node wox.js check` ผ่านจริง
- ยังไม่มีไฟล์เซฟจริงในโปรเจกต์ ผลทดสอบ round-trip ที่ผ่านมาใช้เซฟสังเคราะห์ อย่ารายงานว่าทดสอบกับเซฟจริงแล้วจนกว่าจะมีไฟล์

## ตารางใน editor.js ↔ ตำแหน่งใน bundle

| editor.js | bundle | ไฟล์ |
|---|---|---|
| `TAL` (76) | `Hf` | `c-*.js` |
| `CONF` (41 คู่) | `joe` | `c-*.js` |
| `BG` / `STRUCT` | `CRe` / `LRe` | `c-*.js` |
| `ELEM` | `V_` (+ `TRe`, `ARe`) | `c-*.js` |
| `ROOTT` | `Tie` + จำนวนจาก `ERe` | `app-*.js` / `c-*.js` |
| `FATE` | `Oie` | `app-*.js` |
| `SINEW` | `Aie` | `app-*.js` |
| codec | `Zk` / `r0e` | `app-*.js` |

ชื่อตัวแปรถูก minify ชื่อชนกันข้ามไฟล์ได้ (เช่น `Oie`, `Tie`, `Aie` ใน `c-*.js` เป็นคนละตัว) ต้องค้นในไฟล์ที่ถูกต้องเสมอ

## เมื่อเกมอัปเดต

1. วาง bundle ใหม่แทนไฟล์เดิม
2. `node wox.js check` ถ้าขึ้นว่าหา codec/ตารางไม่เจอ แปลว่าชื่อตัวแปรเปลี่ยน ต้องหาตำแหน่งใหม่ด้วยมือ
3. แก้ตารางใน `editor.js` ให้ตรง แล้วรัน `check` ซ้ำจนผ่าน
4. อัปเดตวันที่และรายการเทียบใน `README.md`

## ค้างอยู่ / ข้อสังเกต

- `localSave(name,data)` ถูกเรียกด้วยพารามิเตอร์ที่ 3 ที่ไม่ได้ใช้
- `diff` / `lint` / `verify` รันกับเซฟจริง 1 ไฟล์แล้ว (ผ่าน, lint เจอ `root.purity`=1000 เกินเพดาน 100 ของเกม) กฎ lint ที่เหลือยังอิงข้อมูลน้อย
- `lint` ยังไม่ตรวจว่า `statSrc.*.talent` ตรงกับผลรวม fx ของพรสวรรค์ (เกมมี clamp/ตัวคูณ ยังไม่ยืนยันสูตร)
