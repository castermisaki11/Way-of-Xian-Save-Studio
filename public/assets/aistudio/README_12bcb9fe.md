# ตัวแก้ไขเซฟ Way of Xian (WOX2)

_อัปเดตล่าสุด 2026-11-20_

เครื่องมือแก้ไฟล์เซฟเกม **Way of Xian** ที่ทำงาน **ในเครื่องเท่านั้น** (ไม่มี `fetch`/อัปโหลดใด ๆ) รองรับไฟล์เซฟที่เกมผนึกด้วยรูปแบบ `WOX2` เปิดได้ทั้ง `.wox` / `.json` / `.txt` (ไฟล์ `.wox` อาจเป็น gzip ตัวแก้ไขจะคลายให้เอง)

> ⚠️ ใช้กับไฟล์สำเนาก่อนเสมอ เกมจะติดป้าย “ชีวิตที่ถูกแก้ไข” กับไฟล์ที่มีการแก้ไข

## วิธีใช้

1. เปิด `ตัวแก้ไขเซฟรี.html` ในเบราว์เซอร์
2. กด **เลือกไฟล์เซฟ (.json / .wox)** → เลือกไฟล์เซฟที่ส่งออกจากเกม
3. ถ้าขึ้น `✓ เปิด ... สำเร็จ · ตราตรวจสอบถูกต้อง` แสดงว่าแฮชและรหัสผ่านถูกต้อง
4. แก้ค่าในแท็บใดแท็บหนึ่ง:
   - **แก้ไขด่วน** — ชื่อ/เงิน/ชื่อเสียง/สุขภาพ/อายุ/ค่าสถานะ 5 ด้าน/**พื้นหลังตระกูล · รากปราณ · เส้นเอ็น · ดวงชะตา**/พรสวรรค์
   - **ข้อมูลทั้งหมด** — ต้นไม้ JSON ทุกคีย์ ค้นหาได้ เปลี่ยนชนิดข้อมูล เพิ่ม/ลบคีย์ แก้เป็น JSON ได้
5. กด **บันทึกไฟล์เซฟ** → ได้ไฟล์ `<ชื่อเดิม>-edited.json` นำไป import เข้าเกมได้

## รายละเอียดการทำงาน

### รูปแบบเซฟ WOX2
```
WOX2<แฮช 16 ตัวอักษร hex>~<ข้อความที่เข้ารหัส>
```
- แฮช: FNV-1a ผสมรหัสลับ รัน xorshift 97 รอบ (มาจาก `Yze()` ใน bundle)
- รหัสลับ: `道法自然:wox2:5f1c-93ab-e27d`
- การเข้ารหัส: เลื่อนเฉพาะอักขระ printable ASCII (33–126) ด้วยตาราง `97×94` ที่สร้างจาก seed เดียวกัน; อักขระไทย/อีโมจิ/ขึ้นบรรทัดใหม่ถูกปล่อยผ่าน
- ตอนเปิดไฟล์ ระบบคำนวณแฮชซ้ำ ถ้าไม่ตรงจะปฏิเสธทันที (กันไฟล์เสียหาย/ถูกแก้โดยไม่ตั้งใจ)

### ปรับค่าสถานะ
ค่าสถานะของเกมคือผลรวมของ `statSrc.<stat>.*` ตัวแก้ไขจึงปรับ `statSrc.<stat>.event` ให้ผลรวมตรงกับค่าที่ตั้ง พร้อมอัปเดต `capSeen` และ `yearFrom` ให้สอดคล้อง (ทั้ง 2 แท็บ)

### กำเนิดและดวงชะตา
แท็บ “แก้ไขด่วน” มีบล็อกแก้ค่าตอนเกิดทั้งหมด (ข้อมูลตรงกับ `CRe/LRe/Tie/V_/Aie` ใน bundle เกม):

- **พื้นหลังตระกูล** → `cls` (12 แบบ: poor…demonic) · **โครงสร้างครอบครัว** → `structure` (both/single/orphan/adopted) — หมายเหตุ: ถ้าเลือก `orphan` เกมตอนสร้างจะตั้ง `cls="poor"` ให้เสมอ
- **รากปราณ** → `root: { type, elements, purity, known }`
  - `type` 7 ระดับ: `none` · `pseudo` (5 ธาตุ) · `four` (4) · `three` (3) · `two` (2) · `heavenly` (1) · `special` (1 ธาตุพิเศษ)
  - ตัวเลขในวงเล็บคือคะแนนสร้างตัวละคร (0/1/2/4/6/8/10) ใช้เช็กความสมเหตุสมผล
  - เปลี่ยนระดับ ระบบจะปรับ `elements` ให้ครบตามจำนวนอัตโนมัติ; ธาตุธรรมดา = ทอง/ไม้/น้ำ/ไฟ/ดิน, ธาตุพิเศษ = สายฟ้า/น้ำแข็ง/ลม
  - `purity` ใส่เลข 1–100, `known` เป็นcheckbox เปิด/ปิดการเปิดเผยราก
- **เส้นเอ็น** → `sinew` 5 แบบ: common/sturdy/fine/tiger/dragon
- **ดวงชะตา** → `destiny: { tier, id }` (มาจาก `CW()` ใน `app-*.js`)
  - `tier` 6 แบบ: `passing` (0) · `support` (2) · `falling` (3) · `dark` (5) · `rival` (7) · `lead` (10)
  - `id` คือรหัสเรื่องราวที่ผูกกับชีวิตนี้ (เว้นไว้ = `null`) **เปลี่ยน tier อย่างเดียวไม่ได้เปลี่ยนเรื่องเดิม** ต้องแก้ `id` ด้วยถ้าต้องการสลับเรื่อง
  - ระดับ `dark` ยังถูกเกมใช้ตัดสินเส้นทางมืด (`J7e(e)`)
- แก้ค่ากลุ่มนี้แล้วติดป้าย `tampered` เหมือนค่าอื่น (เล่นเดี่ยวได้ แต่ไม่ขึ้นทำเนียบ)

### พรสวรรค์
- ตาราง `TAL` มี **76 รายการ** ตรงกับตัวแปร `Hf` ใน `c-GZJ7HVMK.js` ทุก field (id/tier/good/crossing/fx/ชื่อ)
- คู่ที่อยู่ร่วมกันไม่ได้ **41 คู่** ตรงกับ `joe` ใน bundle
- กฎช่อง: ดี `min(8, 5 + talentSlotsUp)` / ร้าย 5 / `crossing` ไม่นับช่อง — ตรงกับ `AD/_D/SD` ในเกม
- เพิ่ม/ลบพรสวรรค์จะปรับ `stats` และ `statSrc.*.talent` ตาม `fx` ให้เหมือน `Zc()` ของเกม

### savedAt
เกมตั้ง `savedAt = Date.now()` ทุกครั้งที่เซฟ และใช้เทียบสล็อตตอนซิงก์ (seed เดียวกัน: `ageMonths` มากกว่าชนะ ถ้าเท่ากันให้ `savedAt` ใหม่กว่าชนะ) ตัวแก้ไขจึงอัปเดต `savedAt` เป็นเวลาบันทึก (และไม่ต่ำกว่าค่าเดิม +1) เฉพาะตอนมีการแก้ไข

### ป้าย tampered
เมื่อมีการแก้ไข ระบบจะใส่:
```js
state.tampered = { at: Date.now(), why: "hand" };
```

เกมใช้ป้ายนี้บอกว่า “เปิดแก้ด้วยมือ” → เล่นเดี่ยวต่อได้ แต่ **ไม่ขึ้นทำเนียบ / แข่งออนไลน์ / อวดของในแชท** ป้ายนี้ถูกป้องกันไม่ให้แก้หรือลบจาก UI

## ข้อควรระวัง

- **สำรองไฟล์เดิมก่อน** — มีข้อความเตือนอยู่ในหน้า UI แล้ว
- ปุ่ม “สูงสุด” ของค่าสถานะใช้ `capSeen` ที่เซฟเคยบันทึก เกมอาจคำนวณเพดานใหม่จาก realm/potential ตอนโหลดแล้วตัดค่ากลับมา
- แท็บ “ข้อมูลทั้งหมด” แก้ `statSrc`, `capSeen`, `statsV` ได้อิสระ → ถ้าแก้ไม่ระวัง เกมอาจ auto-rescale แล้วติดป้าย `tampered` ซ้ำ
- เงินที่ปุ่ม “เต็มทุกอย่าง” ตั้งให้ 99,999,999 สูงกว่าเพดานตรวจจับของเกมมาก (≈ `500,000 + 5,000/ปี`) แม้ติดป้ายแล้วก็อาจถูกฝั่งออนไลน์ปฏิเสธ
- รองรับ **เฉพาะ WOX2 sealed** — เกมยังยอมรับ WOX1/plain JSON ในบางเงื่อนไข แต่ตัวแก้ไขจะขึ้น “ไม่ใช่ไฟล์เซฟ WOX2”
- ถ้าเปิดไฟล์แล้วไม่ได้แก้อะไร ตอนบันทึกจะได้ไฟล์เดิมตรงทุกตัวอักษร (ไม่แตะ `savedAt`)
